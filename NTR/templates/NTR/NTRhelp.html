{% translate "Playing the Game" %}

{% translate "Turns" %}

{% translate "Each round is one Allied turn followed by one French turn. The game ends at Round 10 or as soon as one army is demoralized." %}

{% translate "Unit Types" %}

  • {% translate "Commanders" %}: {% translate "Leadership pieces (Napoleon, Kutuzov, corps generals). They issue command points and activate units, and have no combat strength." %}
  • {% translate "Infantry" %}: {% translate "Standard foot units, strength 1-3." %}
  • {% translate "Guard Infantry" %}: {% translate "Elite units with high combat value. Destroying them causes severe morale loss." %}
  • {% translate "Cavalry" %}: {% translate "High mobility. The first combat commitment incurs a one-time morale penalty." %}
  • {% translate "Artillery" %}: {% translate "Operates on approaches between locales, not from locale centres." %}

{% translate "Hidden Units" %}

{% translate "Units are hidden from the opponent until revealed by combat or reconnaissance. Unrevealed units stay hidden in the saved game data." %}

{% translate "Morale" %}

  • {% translate "Both armies start with 12 morale." %}
  • {% translate "Morale drops from step losses, retreats, Guard destruction and the first Cavalry commitment." %}
  • {% translate "Morale reaching 0 ends the game immediately." %}

{% translate "Victory" %}

  • {% translate "Decisive Victory" %}: {% translate "demoralize the enemy army (morale reaches 0)." %}
  • {% translate "Marginal Victory" %}: {% translate "control starred objective locales at the end of Round 10. A locale needs a commander plus infantry or artillery to count." %}

{% translate "Game Options" %}

  • {% translate "French Reinforcements" %}: {% translate "the French must capture 3 objective locales instead of defending." %}
  • {% translate "Santon Fort" %}: {% translate "adds defensive bonuses to the Santon hill locale." %}
  • {% translate "Team Play" %}: {% translate "4 or 8 players, each commanding specific corps." %}
  • {% translate "Practice Game" %}: {% translate "you play against a bot; practice games are excluded from statistics." %}
  • {% translate "Learning Game" %}: {% translate "excluded from statistics, for new players." %}
  • {% translate "Experienced Game" %}: {% translate "excluded from statistics, for veterans." %}

{% translate "Scenarios" %}

  • {% translate "1 December 1805 (Evening)" %}: {% translate "the allied army is concentrated on the Pratzen Heights with the French deployed before Austerlitz." %}
  • {% translate "2 December 1805 (Morning)" %}: {% translate "the morning of the battle; the allies have begun their move south." %}
