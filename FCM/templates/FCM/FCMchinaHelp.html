{% translate "China Expansion Help" %}

{% blocktranslate trimmed %} These modules are from the Chinese kickstarter (Modian) release from publisher Yikeguang (一刻馆). Splotter was unaware that these existed before I contacted them! Therefore you could consider these modules as "semi-official" but unsanctioned by Splotter.
Games with these modules will therefore be excluded from the stats (except Urban Planning / Urban Planning Plus).
The rules also don't cover all possiblities. Therefore, I have made a few judgment calls to tighten up the rules a bit. In addition, as this content was to designed by Splotter, I'm not sure the playtesting/balancing was quite as thorough! {% endblocktranslate %}

{% translate "Urban Planning" %}

{% translate "Overview" %}
{% blocktranslate trimmed %} Random maps can have a huge amount of variance, producing isolated islands as well as large residential areas. This module allows players to influence map construction and thus the characteristics of the map to be used. {% endblocktranslate %}

Rules
  • {% blocktranslate trimmed %} In turn order, each player may rotate the next tile to be placed, according to the sequence below. Note you can only rotate the next tile - you cannot select or change which tile that is. {% endblocktranslate %}
  • {% blocktranslate trimmed %} After all tiles have been placed, turn order will reset to the same order as when the game started. {% endblocktranslate %}

{% translate "Urban Planning Plus" %}

{% translate "Overview" %}
{% blocktranslate trimmed %} People have asked me in the past about some kind of map tile drafting option. With the addition of the Urban Planning module, which only allows players to rotate the next tile, I decided to add this option as well. {% endblocktranslate %}

Rules
  • {% blocktranslate trimmed %} Same as Urban Planning, except you may now also choose which tile to place, as well as the rotation. {% endblocktranslate %}
  • {% blocktranslate trimmed %} For 6p games then the expansion tiles will be added regardless of whether New Districts has been selected or not. {% endblocktranslate %}

{% translate "Jazz Musicians" %}


{% translate "Overview" %}
{% blocktranslate trimmed %} Jazz originated in the United States in the late 19th and early 20th centuries. This moving music caused people to linger longer. Whenever you have such music in your restaurants, it will cause people to give more generous tips. {% endblocktranslate %}

Rules
  • {% blocktranslate trimmed %} A Jazz Musician can be trained from a Waitress, and requires a salary. There are 6 Jazz Musicians in the game. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Each Jazz Musician will generate $15 in tips during the Dinnertime phase. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Jazz Musicians act as a reverse tie-breaker; ie the person with FEWEST musicians will win ties - so if you have any Jazz Musicians you will lose ties to anyone with fewer Jazz Musicians. {% endblocktranslate %}
    • To clarify, ties are broken in this order
    • 1) As always, the price adjusted for distance is the main factor in determining who wins a sale.
    • 2) Players who tie on price adjusted distance resolve ties in order of who has the best Movie Star.
    • 3) If no player has a Movie Star, ties are resolved in favour of whoever has the FEWEST Jazz Musicians.
    • 4) If there is still a tie, the player with the most waitresses makes the sale.
    • 5) Finally, ties are resolved in turn order.
  • {% blocktranslate trimmed %} As always, employees need to actually be in your structure to count towards tie breakers. {% endblocktranslate %}

{% translate "Delivery Drivers" %}


{% translate "Overview" %}
{% blocktranslate trimmed %} Takeout! Takeout! Finally we can eat at home. Of course, the emergence of takeout has made the price war more intense. {% endblocktranslate %}

Rules
  • {% blocktranslate trimmed %} The Delivery Driver is a base level employee that can be directly hired, and requires a salary. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Note that it is not a 1x employee, but you may only ever have one Delivery Driver in your organisation. {% endblocktranslate %}
  • {% blocktranslate trimmed %} If a residence has 2 or more demand tokens on it, then any restaurant with a working Delivery Driver will reduce the distance to 0. {% endblocktranslate %}
  • {% blocktranslate trimmed %} If you have a Milestone that reduces distance, and it is more favourable to ignore the Delivery Driver, then the Delivery Driver won't be used. EG if you are on the same tile as a house, and have the Ketchup Milestone, your distance will still count as -1; you won't be penalised by having the distance increased to 0 if using a Delivery Driver. So any net positive distance will be reduced to 0. {% endblocktranslate %}

{% translate "Dumplings" %}


{% translate "Overview" %}
{% blocktranslate trimmed %} Dumplings are one of China's classic foods. {% endblocktranslate %}

Rules
  • {% blocktranslate trimmed %} Marketing Dumplings: You cannot directly market dumplings. Instead, they are so tasty that ANY marketed item will also add demand for dumplings. Immediately after a marketing campaign has run, it will run again except the second time it will add Dumplings demand instead of its original item. {% endblocktranslate %}
  • {% blocktranslate trimmed %} The dumpling marketing happens immediately. So if billboards are marketing item A and item B to the same house, the house will add demand for item A, then dumpling due billboard A, and then item B. This would normally cause the maximum demand to be reached, so the dumpling from advertising item B would only be added if the house has a garden. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Dumplings are produced by Dumpling Cooks and Dumpling Chefs. There are 6 cooks, each producing.3 dumplings. The chef Is a 1x employee, and will produce 8 dumplings. {% endblocktranslate %}
  • {% blocktranslate trimmed %} There is a new Milestone for First Dumpling Sold. After Dinnertime, each player who has gained this milestone will choose a new action for their CEO. Their CEO will lose its original action (Hire 1) and replace it with one of the following:
    • 2x Hire 1 Employee or $5 salary reduction (the same as a Recruiting Manager)
    • Get 2 training points; you may train one employee by 2 levels (the same as a Coach)
    • Reduce your base price by $3 (the same as a permanent Discount Manager.
    {% endblocktranslate %}
  • The new CEO action is permanent.

{% translate "Hawker Marketing" %}


{% translate "Overview" %}
{% blocktranslate trimmed %} Hawker trucks driving by, with their loud and engaging music, can't help but attract people's attention to their goods. {% endblocktranslate %}

Rules
  • {% blocktranslate trimmed %} The Hawker Marketeer is a new marketing employee that can be trained from the Marketing Trainee. The Hawker Marketeer requires a salary. There are 6 in the game. {% endblocktranslate %}
  • {% blocktranslate trimmed %} The Hawker Marketeer has a range of 2 and is played in the same way as a Cart Operator - you need to drive this marketeer out of a restaurant and along roads up to a range of 2. You can choose campaign number #21 #22 or #23, and a duration of 1, 2, or 3 turns. {% endblocktranslate %}
  • {% blocktranslate trimmed %} When the marketing campaign activates, it will advertise to any residence directly connected to its route - connections through parks or gardens do not count. {% endblocktranslate %}
  • {% blocktranslate trimmed %} This is the only time the precise orientation of new houses actually matters. Therefore, when using this module, the New Business Developer can place new houses with the garden at the bottom/left/top/right, rather than just horizontally or vertically. {% endblocktranslate %}
