{% translate "Playing the Game" %}

{% blocktranslate trimmed %} You can view unused tiles in the Reserve.
This includes your opponents' unplcaed tiles, as well as face up tile stacks (as you haven't seen their action number)
You can also view each players remaining flex time. {% endblocktranslate %}
{% blocktranslate trimmed %} Any player can rewind the game at any time.
If rewinding the game would "undo" revealing any hidden information, you will be informed before you rewind, and if you continue to rewind it will be recoded in the History. {% endblocktranslate %}

{% blocktranslate trimmed %} At the start of your turn, you must add a tile from your supply to the grid.
After selecting a tile, you may rotate it.
Be Careful! If you ever run out of tiles, you will not be able to take any more actions in the game. {% endblocktranslate %}

{% blocktranslate trimmed %} If a player takes the last tile in a supply pile, the game will end immediately.
You will get a warning before this happens. {% endblocktranslate %}

{% translate "Gameplay" %}

{% blocktranslate trimmed %} Game End: The game will end when EITHER one supply pile runs out, OR only 1 player has tiles left in their supply. {% endblocktranslate %}

{% blocktranslate trimmed %} Tied Scores: If scores are tied at the end of the game, all tied player will jointly win. {% endblocktranslate %}
