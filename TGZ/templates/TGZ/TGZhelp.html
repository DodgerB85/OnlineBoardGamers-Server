{% translate "What are the lines on the map as I move a new item?" %}

{% blocktranslate trimmed %} Each area at a different range (using hubs) from your item is enclosed by a coloured border.
NOTE: On touch devices, you can LONG PRESS in order to see this information. {% endblocktranslate %}

{% translate "How can I view players' moves?" %}
{% blocktranslate trimmed %} Click on "History" from the top menu to open the history. All information is available in the history entry to see what happened. For any moves that occurred on the map, you can also click on the entry to highlight where it happened on the map. You can click entries to see where monuments were built, how monuments were raised, where resources / water were placed, etc. {% endblocktranslate %}

{% translate "How Can I Replay the Game / Copy to a New Game?" %}

{% blocktranslate trimmed %} Select "Replay" from the top menu to go through a "live" replay of the game at any point.
You can use the on-screen arrows, or the Left / Right keyboard arrow keys to step throguh the game.
You can also select any entry in "History" to jump to that point in time.
At any replay point during a player-action, you can click the "Copy Game" button to copy the game at that point in the replay into a new Practice Game. It will then be available to select in the Lobby. {% endblocktranslate %}


{% translate "What is the difference between Rewind and Replay?" %}
{% blocktranslate trimmed %} REWIND will literally roll the game back by one player turn.
So in the bidding phase, it will go back to the last player to make an actual bid,
or if at the first player to bid, it will rewind to the last player to take actions during the last actions phase.
Similarly during actions, it will either rewind to the previous player's action turn,
or if already at the first player, it will rewind to the last player who made an actual bid.
This permanently alters the game state - once you rewind past a move, it no longer exists.
To get back to where you were, simply make the same move(s) again.

REPLAY does not alter the game state in any way. You can view all the moves made from the
start of the game, stepping through move by move, and viewing the game state exactly as it was at that time.
Once you exit replay mode, the game will return to the same state as when you entered replay mode. {% endblocktranslate %}

{% translate "What is the Map Inspector?" %}

{% blocktranslate trimmed %} During your turn when you are not in the middle of an action, or at any point during someone else's turn, you can click on the "Map Inspector" button to enable inspection of the map.
All monuments and craftsmen will be highlighted, and you can click an item to view which squares are accessible and how many hubs it requires to get there. {% endblocktranslate %}

{% translate "Where can I view available / taken items?" %}

{% blocktranslate trimmed %} Click on "Reserve" from the top menu to view all items. Click an individual player's plaque to view their items. {% endblocktranslate %}

{% translate "What is the information when bidding?" %}

{% blocktranslate trimmed %} When bidding, your bid selection (eg Bid 1) will also show how many cows you would have for actions if all other players pass. This could increase if bidding continues and more cows are put on on your plaque (or plaques with Shadipinyi).
If you adore Elegua, eligible bids will also be marked with your total cost after this bonus. {% endblocktranslate %}

{% translate "Why did I miss my bidding turn?" %}
{% blocktranslate trimmed %} Turns where you cannot do anything are skipped, For example if you do not have enough cows to make an increased bid. Check the history for the reason a player's turn was skipped. {% endblocktranslate %}

{% translate "What is the change with Dziva?" %}
{% blocktranslate trimmed %} Dziva is considered a bit of a weak choice with the bonus as published.
Therefore, there is a small change to allow you alter prices when you choose Dziva as well as at the start of your turn.
There are a lot of discussions about this on BGG, and this addition has been sanctioned by Splotter.
As Dziva is a bit weak without this, and definitely not overpowered with this, then there are no plans to make this a setup option.
Dziva will always have this little extra ability. {% endblocktranslate %}

{% translate "What Hotkeys are there?" %}
{% blocktranslate trimmed %} R / r = Rotate
Left Arrow Key = Back one step in Replay
Right Arrow Key = Forward one step in Replay {% endblocktranslate %}

{% translate "How can I score points?" %}

{% blocktranslate trimmed %} You score Victory Points based on the level of each of your monuments.
In addition, you get Victory Points for each Craftsman you build. {% endblocktranslate %}

{% translate "Who wins? (And what about Xango?)" %}
{% blocktranslate trimmed %} Your Victory Requirement (VR) starts at 20 points.
Taking gods, specialists, and technologies increases your VR, so you will need more points to win.
You score Victory Points as above, giving you a score in the format VP / VR.
When your VP equal or exceed your VR, you can win the game. This is checked during the "Let Us Compare Mythologies" phase.
If multiple players exceed their VR in the same round (ie have more VP then VR) then ties are decided as follows:
  • 1st tiebreaker: Highest overshoot of VR
    (Highest net score, once you calculate VP - VR)
  • 2nd tiebreaker: If players tie on VP - VR (ie overshoot by the same amount) ties are won by Xango
    In this context, you can think of Xango as being effectively -2.5 VR
  • 3rd tiebreaker: Highest total VP
    If players are still tied, ignore the VR and look at the VP. Highest wins.
  • 4th tiebreaker: Any remaining tied players are decided in turn order. Earliest wins.
{% endblocktranslate %}
