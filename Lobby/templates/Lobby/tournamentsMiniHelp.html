{% url 'helpTournaments' as tournaments_help_url_old %} For Main Tournaments see Tournaments Help

Mini Tournaments function similarly to tournaments; please check the Tournaments Help Page for general information.

The main differences are that Mini Tournaments can be created by anyone, are meant to be played at a faster pace, they have a smaller player pool, and prioritise playing games over player count. Min Tournaments will always start with the correct number of players to fill every game, eg 12 total players with 4 players per game.
However, if in later rounds there are not enough players to start a full game, due to lost lives or kickouts, then a game will still be created provided the minimum number of players are available.

{% translate "What are the formats?" %}
{% blocktranslate trimmed %} Rounds consists of (currently) 4 rounds, where all players are included in the games, after which there is a short knockout of all players on top points to determine the overall winner.

Two Lives is like double elimination; once you've lose twice then you're out of the tournament.

Points functions the same as Rounds, except that instead of “winner takes all”, points awards points per position - unlike the other formats which are winner takes all. 5 player games award 16 / 8 / 4 / 2 / 1 points, 4 player games award 8 / 4 / 2 / 1 points, and 3 player games award 4 / 2 / 1 points per position. {% endblocktranslate %}

{% translate "How are game players decided?" %}
{% blocktranslate trimmed %} Initially game players are drawn randomly. After this, players are ranked by number of wins / (or points in a points. tournament). In 2p, players will play the closest people to them that thay haven't already played. For 3p+ the system will create games so that as many people as possible are playing new players. This is priorisied over current points/ranking, so the current "top" player may end up in a game with the current "bottom" player.
If there are at least enough players to start a game, then a game will start, even if there aren't enough player to match the tournament "Players per Game" setting.
If there is a single player left, then the lowest ranked player who has not yet received a bye will receive one. {% endblocktranslate %}

{% translate "How do kickouts work?" %}
{% blocktranslate trimmed %} If someone is kicked out then they are ejected from the tournament. They will lose both lives in Two Lives, and be removed from a Rounds/Points tournament. {% endblocktranslate %}

{% translate "What else should I know?" %}

Notifications are sent out at the start of every new tournament game. If you finish quickly there could be several days until your next game starts, so it is strongly recommended to have at least one form of notification enabled in your profile. {% endblocktranslate %}
