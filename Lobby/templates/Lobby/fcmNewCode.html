{% translate "What's this about?" %}

{% blocktranslate trimmed %} In short, FCM needed a big recode. It is mainly under-the-hood things, so you hopefully won't notice that much difference. {% endblocktranslate %}

{% blocktranslate trimmed %} That being said, there are a lot of internal changes, so keep an eye an things, and report any new bugs that you find. {% endblocktranslate %}

{% translate "What isn't 'Under-the-hood'?" %}

{% blocktranslate trimmed %} I've added the ability to play the whole payday / fridge phase after your working day turn. {% endblocktranslate %}

{% blocktranslate trimmed %} So instead of simply paying for everyone / no-one, you can pre-fire employees as you wish. {% endblocktranslate %}

{% blocktranslate trimmed %} You can also pre-set which items you'd like to store in your fridge, in priority order. {% endblocktranslate %}

{% blocktranslate trimmed %} There is also a summary at the end of the working day to show what you did in each sub-phase, and remind you if you missed anything. {% endblocktranslate %}

{% blocktranslate trimmed %} For restructuring, you now have a mini-beach visible at all times, and can directly select cards from there. {% endblocktranslate %}

{% translate "Why did it need a rewrite?" %}

{% blocktranslate trimmed %} 99% of the time it didn't. But very occasionally it would do odd things. {% endblocktranslate %}

{% blocktranslate trimmed %} EG after the first turn of a game that had salaried employees that it was possible to directly hire, the game would pause until every player had "looked" at the game, before moving on automatically if they didn't need to pay anything. {% endblocktranslate %}

{% blocktranslate trimmed %} Sometimes it would display oddly if you had the MS to pay in food. {% endblocktranslate %}

{% blocktranslate trimmed %} Occasionally it would wait during the marketing phase until a certain player had looked at the game. {% endblocktranslate %}

{% blocktranslate trimmed %} These should be fixed, as well as making it easier to fix and improve the code in the future. {% endblocktranslate %}

{% translate "Was it worth it?" %}

{% blocktranslate trimmed %} Ha, well it took literally 10s of hours to do; probably over 100 i guess, with the improvements added as well. {% endblocktranslate %}

{% blocktranslate trimmed %} But it was needed to fix those 1% situations, and make the code a lot easier to work with in the future! {% endblocktranslate %}
