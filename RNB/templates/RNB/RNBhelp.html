{% translate "Playing the Game" %}

{% blocktranslate trimmed %} Roads & Boats has a lot of complex interactions with the goods, transporters, and buildings. To remove the need for lots of pointless and tedious interactions, certain shortcuts have been added to smoothen the user experience. For example, the game will allow you to select a good you wish to ferry (move over a river with a boat) even when the transporter is already full, and then allow you to immediately drop it on the other side of the river. Such shortcuts are given in each of the phase sections below. {% endblocktranslate %}

{% translate "Gameplay by Phase" %}

{% translate "All Phases:" %}

{% blocktranslate trimmed %} The only thing you really own on the map are your transporters! Therefore, interacting with the map is almost always driven through your transporters. You will start by selecting a transporter, and then interacting with other items using that transporter. {% endblocktranslate %}

{% blocktranslate trimmed %} You can select a transporter directly on the map. You can also select it by clicking on a tile, and then clicking on the transporter in the Zoom Tile. If the Zoom Tile is still so crowded that you cannot select it, then each area of the tile is listed underneath, and will always display all items. So alternatively you will always be able to select an item in this Zoom Area. {% endblocktranslate %}

{% blocktranslate trimmed %} Once a transporter is selected, you can interact with goods/buildings either directly on the map, or using the big tile in the Zoom Panel or below in the Zoom Area. {% endblocktranslate %}

{% translate "Conflict" %}

{% blocktranslate trimmed %} After playing any main phase, you must pre-set a conflict phase. You may select the option “Wait & See” if you wish to decide whether or not to call conflict later. As soon as any player calls conflict, then each player will make their decisions about praying and turn order. If no one calls conflict then the game will move to the next main phase. {% endblocktranslate %}

{% translate "Presetting phases" %}

{% static 'RNB/help/pseudoResHelp.jpg' as pseudo_img_url %} {% blocktranslate trimmed %} To help speed the game up, every player is allowed to perform a move in the current phase. Once you have set this move, then you will have further options to set future phases. If you are setting a future production phase, then mines with only 1 type of good will produce that good. Where a mine has more than 1 good, a “pseudo” good will be produced during the pre-phase. This will allow you to still pick up and transport the produced good if you don't mind if it is either iron or gold. When the pre-set turn is processed, this”pseudo” good will be replaced with the actual mine output. If you want to know which good the mine will produce, then you can wait for the game to move to that production phase. {% endblocktranslate %}

{% blocktranslate trimmed %} Once the current player has moved, then all pre-set moves will be processed in turn order. Should any action no longer be possible, eg because another player has moved a good, then that player will be notified that they need to re-do their turn. When they enter the game, their actions will be re-done until the action that was no longer possible. {% endblocktranslate %}

{% translate "Roads & Boats Help" %}

{% translate "Playing the Game" %}

{% blocktranslate trimmed %} Roads & Boats has a lot of complex interactions with the goods, transporters, and buildings. To remove the need for lots of pointless and tedious interactions, certain shortcuts have been added to smoothen the user experience. For example, the game will allow you to select a good you wish to ferry (move over a river with a boat) even when the transporter is already full, and then allow you to immediately drop it on the other side of the river. Such shortcuts are given in each of the phase sections below. {% endblocktranslate %}

{% translate "Gameplay by Phase" %}

{% blocktranslate trimmed %} All Phases: The only thing you really own on the map are your transporters! Therefore, interacting with the map is almost always driven through your transporters. You will start by selecting a transporter, and then interacting with other items using that transporter. {% endblocktranslate %} {% blocktranslate trimmed %} You can select a transporter directly on the map. You can also select it by clicking on a tile, and then clicking on the transporter in the Zoom Tile. If the Zoom Tile is still so crowded that you cannot select it, then each area of the tile is listed underneath, and will always display all items. So alternatively you will always be able to select an item in this Zoom Area.

Once a transporter is selected, you can interact with goods/buildings either directly on the map, or using the big tile in the Zoom Panel or below in the Zoom Area. {% endblocktranslate %}


{% blocktranslate trimmed %} Production Phase: Mines produce automatically before the Production Phase Conflict is resolved.
Primary producers all produce automatically at the start of the phase.
In addition, secondary producers with no transporters present will also automatically produce, if they are able to do so.
At the end of the phase, all remaining secondary producers will produce if they have remaining capacity and suitable input goods.
You can select a transporter to pickup/drop/ferry goods, or interact with any buildings.
If a tile has any of your transporters present along with a building that is able to produce, it will be highlighted so you can activate it directly.
A building will place its output onto the tile in the same area as the building.
If a building is not highlighted then check the Zoom Area to find out why.
Research is carried out in the production phase. When selecting a transporter, your research options will be shown as bubbles around the transporter. {% endblocktranslate %}

Production Phase Shortcuts:
  • When you select a secondary building, it will automatically use input goods in the following priority order:
    • Goods on the tile
    • Goods on the selected transporter (if any)
    • Goods on any of your transporters
    This saves you having to deposit every good on to the same tile area before performing your build action.
  • For the Paper Mill and Coal Burner with 2 different possible input goods, the goods will be automatically selected for you if there is no choice to make
  • When converting a donkey into a wagon, any goods on the donkey will automatically transfer to the wagon.
  • New water transporters with only 1 valid location to start will automatically be placed in that location.
  • The same resource pickup/drop/ferry shortcuts as in the Movement phase also apply here.
{% blocktranslate trimmed %} Movement Phase: Select a transporter. You can then click goods to load them, or click goods on the transporter to unload them. When you click a transporter, the tile areas you can move to will automatically highlight. If you are unable to move a transporter, check the Zoom Area to find the reason. You will either have no moves remaining, or you will have picked up a good/transporter that has itself already moved.

Movement Phase Shortcuts:
  • If there is only 1 valid location for dropping a good, then it will be selected automatically.
  • If there is more than 1 possible location, or if there is a water transporter present that could perform a ferry, then you will be shown all possible options for the final destination of the good.
  • Similarly when picking up a good, if the good could be ferried to your location for pickup, it will be highlighted to allow you to pick it up directly.
  • You may also "steal" goods direcly from your OWN transporters, as a shortcut to dropping a good on the tile and then picking it up again
  • You can only unload a transporter at the start of the Movement Phase. However, the game will allow you to drop a transporter that has been picked up but not moved, as that is the equivalent of just “undoing” the action.
  • Geese cannot be following any of your transporters at the end of your movement phase - they must be on a tile. If any geese followers have only one possible location to be dropped, they will be dropped there automatically. If any geese are following a water transporter on a sea tile, then they cannot be dropped, and you must manually choose their destination before ending your turn.
{% endblocktranslate %} {% blocktranslate trimmed %} Building Phase: Select a transporter.
If you are able to build any buildings these will be displayed in the Build Panel which will appear just below that transporter.
If you are able to start a build wall / bridge / road or demolish wall action, these will be shown after the available buildings.
Click a wall / bridge / road option, and your available choices will be highlighted on the map.

Building Phase Shortcuts:
  • If you have multiple transporters on a tile, eg a donkey and raft, then all possible options for building a road/wall will be highlighted if it could be reached by any of your transporters on that tile.
  • When you build anything, goods will automatically be used in the following priority order:
    • Goods on the tile
    • Goods on the selected transporter (if any)
    • Goods on any of your transporters
    This saves you having to deposit every good on to the same tile area before performing your build action.
  • The same resource pickup/drop/ferry shortcuts as in the Movement phase also apply here.
{% endblocktranslate %} {% blocktranslate trimmed %} Wonder Phase: Goods on your home tile will be displayed above the map. Click these goods to add them to your next brick. As soon as sufficient goods have been added, then your next brick will be added to the Wonder. You may pickup/drop/ferry goods on any tile. The same resource pickup/drop/ferry shortcuts as in the Movement phase also apply here. {% endblocktranslate %}
