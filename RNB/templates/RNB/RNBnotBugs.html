{% blocktranslate trimmed %} Before reporting a bug, please check that you have not run into one of the deliberate rules quirks below. In most cases the game is following the Roads & Boats rules exactly. {% endblocktranslate %}

{% translate "Boats, rivers and docks" %}

{% blocktranslate trimmed %} Dropping a boat (a water transporter) is more restricted than dropping goods. A docked location is one particular shore — the coastline between a land tile and the sea tile the boat came from — so these drops are not allowed: {% endblocktranslate %}

  • {% translate "A boat in a river cannot unload another boat into a docked location." %}
  • {% translate "A boat in open sea cannot unload another boat into a docked location." %}

{% blocktranslate trimmed %} This follows the rules: a boat in a river may unload another boat only in that same river, and a boat on a shore may unload another boat only on that same shore. Goods are not affected — you can still ferry goods normally. To unload a boat, move the carrying transporter to the river or shore where you want the boat to end up, then unload it there. {% endblocktranslate %}

{% translate "Moving goods on the same tile" %}

{% blocktranslate trimmed %} You can pick up and drop goods anywhere within a single tile during any main phase. This is deliberate: a tile is divided into areas and can hold many transporters, buildings and goods, and shuffling goods locally saves pointless pick-up/drop micro-management. {% endblocktranslate %}

{% translate "It only works within one tile. Goods still have to be carried to another tile by a transporter, and moving a transporter to another tile still costs movement." %}

{% translate "Transporters carrying transporters" %}

{% blocktranslate trimmed %} While one transporter carries another, neither may carry anything else. In the Production phase this means the carrying transporter cannot interact with a building: a loaded transporter is cargo, not a worker. {% endblocktranslate %}

{% blocktranslate trimmed %} A transporter that is being carried cannot act at all, so select the transporter that is carrying it instead. If you need the loaded transporter for production, unload it at the start of a later Movement phase. {% endblocktranslate %}

{% translate "When a transporter cannot move" %}

{% blocktranslate trimmed %} Click the transporter or its tile and check the Zoom Area. It lists every transporter on the tile, its remaining moves, and whether it has already moved, which usually explains the problem straight away. {% endblocktranslate %}

{% blocktranslate trimmed %} The usual reasons are that the transporter has no moves left, or that you have picked up a good or transporter that has itself already moved this phase. Loading and unloading does not give a transporter fresh movement. {% endblocktranslate %}
