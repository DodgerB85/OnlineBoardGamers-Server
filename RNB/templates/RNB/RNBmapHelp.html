{% translate "Map Verification" %}

{% blocktranslate trimmed %} When you create a map in the Map Editor, it starts out as an unverified map. . {% endblocktranslate %}

{% blocktranslate trimmed %} Verification is performed manually by me. Verified maps are marked with a green [Verified] label. {% endblocktranslate %}

{% translate "Creating a Map" %}

{% blocktranslate trimmed %} To create a new map, use the hex tile palette at the top of the Map Editor to select terrain tiles and place them on the grid. Give your map a name and description, then click the save button. Your map will be saved to the database as an unverified map. {% endblocktranslate %}

{% blocktranslate trimmed %} Only the map creator (or the admin) can replace or update an unverified map. Once a map is verified, only the admin can modify it to protect the official map collection. {% endblocktranslate %}

{% translate "Map Validation Rules" %}

{% translate "The Map Editor will prevent you from saving a map that does not meet these minimum requirements:" %}

  • {% translate "The map must have at least as many hexes as the player count multiplied by 3." %}
  • {% translate "All hexes on the map must be connected (no isolated hex groups) - use the void hexes to create map breaks." %}
  • {% translate "All river connections between hexes must be properly matched." %}
  • {% translate "The map must have a name and description." %}

{% translate "How to Get a Map Verified" %}

{% blocktranslate trimmed %} I will review the map list periodically to verify maps. Please ensure your map has a good name, and includes the designer credit in the description. Please use some variation in similar hexes, ie for a big sea area, use a variety of sea hexes, not just the same one. Same goes for pastures / woods / etc. If you are still working on a map, then please include it in the description, eg 'test' or 'draft'. To help me identify maps that are ready for release, please add "FINAL" to the end of the name. I will then review the map and remove the 'FINAL' from the title.

There are no paritcular 'rules' as to how a map must 'be'. Any map that looks playable can get verified! {% endblocktranslate %}
