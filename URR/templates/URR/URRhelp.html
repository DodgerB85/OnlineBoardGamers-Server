{% translate "Terrain" %}

{% translate "Cities" %}
{% translate "City artwork distinguishes city land from ordinary fields. In holdings, the small city picture counts cities already included in the terrain total." %}

{% translate "Player markers" %}
{% translate "Player colours identify landowners and payment recipients. On the map, a faded marker inside a dashed frame means the land has been sold and is available to buy." %}

{% translate "State and treasury" %}
{% translate "The state badge identifies a state; the treasury board shows its money, crews, and harvest. State colours on equipment identify its owning state. Private cash and state treasury money are separate." %}

{% translate "Primogeniture" %}
{% translate "This marker identifies the player with primogeniture. A pending bid reserves private cash; Available shows the amount left to spend." %}

{% translate "Waterworks and crews" %}
{% translate "The number on a piece is its capacity. For pumps it is canal reach; for reservoirs it is water capacity. M means unlimited. In the crew panel, the number is digging capacity; two pieces represent a split crew, and faded crews have already dug." %}

{% translate "Equipment cards" %}
{% translate "The equipment card shows the current capacities and prices. Select it to enlarge it. The crew, pump, and reservoir buttons show the action and cost before you confirm." %}

{% translate "Nation cards" %}
{% translate "Select a nation card to read it at full size. Map locates its homeland. Player or state badges beside a nation show its owner." %}

{% translate "Map highlights" %}

  • {% translate "Yellow:" %} {% translate "The selected or focused hex. Its details appear below the map." %}
  • {% translate "Purple:" %} {% translate "An available Calah waterwork site or Barahshum canal destination. The map hint and hex description identify the exchange." %}
  • {% translate "Amber:" %} {% translate "Land eligible for a mandatory crew funding sale, or a waterwork eligible for removal when storing harvest. Select a hex to see which applies." %}
  • {% translate "Cyan outline:" %} {% translate "An available water-routing destination. Numbered blue badges match the destination list; the source has a dashed outline and a Source label. A small cyan dot on a hex marks irrigation." %}
  • {% translate "Blue lines:" %} {% translate "Canals. The thicker line is the canal path you are drafting. The moving cyan dot previews the selected water route." %}

{% translate "Playing the Game" %}

{% translate "The rows above the board show player order and active state order. Select a player or state to inspect its holdings; the status panels otherwise follow the current decision." %}

{% translate "Overview compares state treasuries, monarchs, owned land, crews, harvest, and order, plus each player's ownership across states. Select a name to inspect its existing status panel. Stars mark monarchs or ownership leaders; sold land is excluded from ownership counts." %}

{% translate "Inspected states stand out on the map while other hexes are dimmed and action highlights are hidden. Show owned land in the player panel highlights that player's holdings in the same way. Clear map inspection restores the available action highlights. The action panel identifies the acting state and player separately from the inspected panels." %}

{% translate "Equipment supply shows the current era prominently. All eras expands the remaining cards. The next era begins with the first purchase from its supply. Development progress identifies optional digging and purchasing, and whether a maintenance crew is required before ending." %}

{% translate "Land prices show the current market price in bold and the fixed colonization cost below it. The second row uses city artwork for city prices. Market after plan previews price changes from queued sales before you confirm. Small city markers in a player's holdings count cities included in the terrain totals." %}

  1. {% translate "Independent nations:" %} {% translate "Buy the current treaty nation, or expand another nation's row to make an offer. Map locates that nation's homeland. Select the artwork to read a card at full size; use its zoom controls to enlarge it further. During an auction, bid or withdraw from the current nation. Bidders who cannot afford the minimum withdraw automatically." %}
  2. {% translate "Settlement:" %} {% translate "Select land on the board. Queue a purchase and any sales, review the cash and any leadership changes after trade, then complete the trade. Sales before and after buying are separate batches. Pass when finished, or bid for primogeniture." %}
  3. {% translate "Development:" %} {% translate "States dig canals before purchasing equipment. Select an unused crew and trace adjacent areas on the map. Then hire crews or select a site for a pump or reservoir. Another landowner may need to accept your proposal. Private cash and state treasuries are separate. If a required crew needs land sales, select the highlighted sites and review the final cash and any leadership changes before confirming." %}
  4. {% translate "Rainy season:" %} {% translate "Select a highlighted destination to route water. At harvest, review the payouts before distributing it, or store it in the state treasury and remove a waterwork when required. Empty harvests resolve automatically." %}

{% translate "On a small screen, Show actions opens the drawer at the bottom of the screen. It closes while tracing a canal. Selecting a player or state brings its status into view; Back to board returns to the map. Use the zoom controls to enlarge the map, and select the percentage to fit it again." %}

{% translate "For keyboard play, Tab focuses the board. Arrow keys move between adjacent hexes; Enter or Space selects a hex. Tab moves on to the other controls." %}

{% translate "Your actions stay in a local draft until End Turn. Undo reverses your last draft action; Reset Turn restores the start of your current decision session. End Turn saves the draft and hands control onward. These controls apply to every phase, including auctions, agreements, development, water routing, and harvest. Refreshing or leaving before End Turn discards the draft. Use the shared Rewind control for a previously saved turn." %}

{% translate "Selecting a destination in the list also selects it on the map. During water routing, Confirm beside the selected hex adds that allocation to your draft; Cancel clears the selection. Expand Dig canals, Buy equipment, or Buy a nation during development. Choose a construction or exchange action to highlight its available sites." %}

{% translate "History records moves, treasury changes, state emergence, and leadership changes. Escape closes a card preview or the history panel. In Replay, select a history entry or use the step controls to inspect earlier positions. Exit Replay returns to the live game." %}
