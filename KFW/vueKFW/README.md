    Create a new branch (the name should relate to your issue)
    Do the code
    Submit a pull request to merge it with main

Instructions

    Check out the comments in each file.
    Also, the index.html is set up as if it has been generated by the server, with an example set of server data.
    This should allow the project to be kept separate from the backend as long as possible, or even linked to a dummy backend with the example data.
