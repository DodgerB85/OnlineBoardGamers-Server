{% translate "Playing the Game" %}

{% blocktranslate trimmed %} You can view unused / possible upcoming season tiles in the Reserve. {% endblocktranslate %}

{% blocktranslate trimmed %} You can also view each players remaining flex time. {% endblocktranslate %}

{% blocktranslate trimmed %} Any player can rewind the game at any time. {% endblocktranslate %}

{% blocktranslate trimmed %} If rewinding the game would "undo" revealing any hidden information, you will be informed before you rewind, and if you continue to rewind it will be recoded in the History. {% endblocktranslate %}

{% blocktranslate trimmed %} At the start of your turn, any workers used for bidding/actions since your last turn will have a highlight so you can easily see what moves other players have made. {% endblocktranslate %}
{% blocktranslate trimmed %} During village expansion, edges with roads on will have an additional icon so you can clearly see where the roads are in your village. If you place a tile that could interfere with a chain of boats coming from your home tile, the tile will display a Caution icon. {% endblocktranslate %}

{% translate "Hidden Information" %}

{% blocktranslate trimmed %} During a game of Keyflower, players will have a number of hidden workers and skill tiles. The exact type of these items could be known at some point, eg if a player receives a green worker, or when a player collects resources from a boat. In a practice game, you play as all players, so there is no hidden information - all players' items are always displayed. In a normal game, there are 3 options for displaying this hidden information, chosen when the game was created. {% endblocktranslate %}

{% translate "High Knowledge Level:" %}
{% blocktranslate trimmed %} You will be shown the most detailed information that you could get from analysing the history. For example, you know each player starts with 8 hidden workers. Later, if a player received 3 blue workers from a boat, and then bids with 2 blue workers, you would know that they have at least 1 more blue worker available to use (plus any blue workers from their "hidden" collection). {% endblocktranslate %}

{% blocktranslate trimmed %} With "High-" any "Known" workers just before a boat is picked will be moved to "Unknown" workers {% endblocktranslate %}

{% translate "Medium Knowledge Level:" %}
{% blocktranslate trimmed %} This uses a more “gut feeling” approach. You won't be told how many hidden items a player has. When you do know for certain that a player has received certain items, eg 1 blue 2 red and 3 yellow workers from a boat, then this information will be displayed by showing the relative amount of each colour that you know a player has. So the yellow worker will be filled in the most, red about half, and blue the least. {% endblocktranslate %}

{% blocktranslate trimmed %} With "Medium+" the white worker will show the total workers a player has (instead of "?") {% endblocktranslate %}

{% translate "Low Knowledge Level:" %}
{% blocktranslate trimmed %} This provides you with the least information - you will need to rely on gut and intuition. During the game, the history will only be displayed up to your last 2 turns. You will not be given any information by the game as to how many of each item other players may have. {% endblocktranslate %}

{% translate "Gameplay by Phase" %}

{% translate "Bidding & Actions:" %}

{% blocktranslate trimmed %} You can add workers directly from your supply, or from a tile where you are outbid. Alternatively, you can use the popup which will show you all possible workers you could pick - either from your supply, or where you are outbid. If a tile action would result in you revealing some hidden information, then this action will be carried out after you have ended your turn. The result will be displayed on screen, and visible to (only) you in History. {% endblocktranslate %}

{% translate "Boat Resource Collection:" %}

{% blocktranslate trimmed %} After you have collected your boat resources, you may immediately move on to expanding your village, if you have tiles to add. This allows you to build your village without having to wait for all the other players to choose a boat - which generally would have no effect on your village expansion anyway. {% endblocktranslate %}

{% translate "Village Expansion:" %}

{% blocktranslate trimmed %} Village Expansion is played simultaneously. You can rotate a tile before placing it, click on it to place it anywhere in your village (even if it would currently be illegal), and then continue to rotate it in place. Click any placed village tile it pick it up again. {% endblocktranslate %}

{% translate "You cannot end your turn until you have made a legal village." %}

{% translate "Winter Boat Collection:" %}

{% translate "This phase is played simultaneously by all players." %}

{% translate "Final Scoring:" %}

{% blocktranslate trimmed %} Final scoring is played simultaneously. During final scoring, any resources that are scoring “on the tile” will be left in place, and the rest gathered on your home tile to allocate as you wish. You can always click a resource that has been left on a different tile to move it to your home tile and allocate it to score elsewhere. {% endblocktranslate %}
